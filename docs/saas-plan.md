# Zyro Support — SaaS পরিকল্পনা

তারিখ: 2026-10-06 · সিদ্ধান্ত নিয়েছেন: Zisan

## সিদ্ধান্ত
- এই প্রজেক্টই আলাদা পণ্য হিসেবে বড় হবে (BSOL-এর ভেতরে না)।
- প্রতিটা কোম্পানি নিজের Meta কার্ড (WhatsApp খরচ) আর নিজের AI key দেবে। আমরা নেব শুধু সাবস্ক্রিপশন ফি।
- প্রথম লক্ষ্য: ISP Digital ব্যবহারকারী ISP-রা।
- **Century Link Network অক্ষত থাকবে।** এখনকার সার্ভিস (`zyro-support`, পোর্ট 8993) নতুন সিস্টেম পুরো পরীক্ষিত না হওয়া পর্যন্ত বদলানো হবে না।

## নকশা (প্রস্তাবিত)

```
WhatsApp (Meta) ──webhook──▶  Python ইঞ্জিন (FastAPI)          Laravel প্যানেল (Tyro Dashboard)
                               • phone_number_id → কোম্পানি       • সুপার-অ্যাডমিন: কোম্পানি, প্যাকেজ, পেমেন্ট
                               • কাস্টমার যাচাই, বিলিং লুকআপ      • কোম্পানি: সেটিংস, এজেন্ট, ইনবক্স
                               • AI উত্তর, টিকেট, ভয়েস            • Embedded Signup (WhatsApp যুক্ত)
                                          │                                     │
                                          └──────────── PostgreSQL ─────────────┘
```

- **Python ইঞ্জিন:** এখনকার কোড (webhook, ispdigital, AI, টিকেট, ভয়েস) — পরীক্ষিত, তাই আবার লেখা হবে না; শুধু প্রতিটা কাজ কোম্পানি-ভিত্তিক হবে।
- **Laravel + Tyro Dashboard:** ইউজার/রোল/2FA/audit log/CRUD তৈরি অবস্থায় পাওয়া যায়; BSOL-এর মতো পরিচিত স্ট্যাক। মাল্টি-কোম্পানি স্কোপ আর চ্যাট ইনবক্স আমরা যোগ করব।
- **একটাই PostgreSQL ডাটাবেস** (`zyro_support`), দুই অংশই ব্যবহার করবে। সব টেবিলে `company_id`।

## ডেটা মডেল (মূল টেবিল)
| টেবিল | কাজ |
|---|---|
| companies | নাম, স্ট্যাটাস, প্যাকেজ, ট্রায়াল/মেয়াদ |
| users | লগইন; `company_id` (সুপার-অ্যাডমিনের ক্ষেত্রে null) |
| company_user roles | Owner / Admin / Agent (কোম্পানি-ভিত্তিক) |
| wa_accounts | WABA ID, phone_number_id, এনক্রিপ্টেড token, কোম্পানি |
| billing_connections | কোম্পানির বিলিং সফটওয়্যার (এখন ISP Digital), URL, ইউজার, এনক্রিপ্টেড পাসওয়ার্ড |
| ai_keys / ai_settings | কোম্পানির AI প্রোভাইডার, key, মডেল, নির্দেশনা, স্বাক্ষর, বট মোড |
| contacts | WhatsApp নম্বর ↔ কাস্টমার লিংক, যাচাইয়ের অবস্থা, বট বন্ধ/চালু |
| conversations, messages | চ্যাট, মিডিয়া, কে উত্তর দিল (বট/এজেন্ট), কোন এজেন্টে অ্যাসাইন |
| drafts, tickets_log | AI খসড়া, টিকেট খোলার রেকর্ড |
| templates, campaigns | Meta template, কাকে কবে পাঠানো হলো, খরচ |
| plans, subscriptions, payments | প্যাকেজ, বিকাশ পেমেন্ট |
| audit_log | কে কী বদলাল |

কোম্পানির সব গোপন তথ্য (token, পাসওয়ার্ড, AI key) এনক্রিপ্ট করে রাখা হবে; এক কোম্পানির কোনো ইউজার অন্য কোম্পানির ডেটা কখনো দেখবে না (প্রতিটা কোয়েরিতে company_id স্কোপ + টেস্ট)।

## ধাপসমূহ
1. **ভিত্তি:** PostgreSQL ডাটাবেস + স্কিমা; Laravel প্রজেক্ট + Tyro Dashboard; সুপার-অ্যাডমিন লগইন; কোম্পানি তৈরি। (Century Link-এ কোনো প্রভাব নেই।)
2. **কোম্পানির সেটআপ পেজ:** বিলিং সংযোগ (টেস্ট বোতামসহ), AI key, বটের নির্দেশনা/স্বাক্ষর/মোড, এজেন্ট যোগ ও রোল।
3. **ইঞ্জিন মাল্টি-কোম্পানি:** Python সার্ভিসের নতুন কপি (`zyro-engine`) — webhook এলে phone_number_id দেখে কোম্পানি বের করবে, সেই কোম্পানির বিলিং/AI/সেটিংস দিয়ে কাজ করবে। আলাদা পোর্টে চলবে, Meta-র webhook এখনো পুরনোটায়।
4. **এজেন্ট ইনবক্স:** কথোপকথনের তালিকা, অ্যাসাইন, take over, নোট, মিডিয়া, template পাঠানো, ক্যাম্পেইন।
5. **WhatsApp যুক্ত করা:** Embedded Signup (Coexistence সহ) — **Meta App Review পাস হওয়ার পর** অন্য কোম্পানির নম্বর যুক্ত করা যাবে।
6. **প্যাকেজ ও পেমেন্ট:** প্যাকেজ (এজেন্ট/মেসেজ সীমা), ট্রায়াল, বিকাশ পেমেন্ট, মেয়াদ শেষে বট বন্ধ।
7. **Century Link স্থানান্তর:** সব সেটিংস, key, কথোপকথন কোম্পানি #১ হিসেবে নতুন সিস্টেমে কপি → পাশাপাশি পরীক্ষা → Meta webhook নতুন ইঞ্জিনে → পুরনো সার্ভিস কয়েকদিন ব্যাকআপ হিসেবে চালু রেখে বন্ধ।

## বাধা ও ঝুঁকি
- **Meta Tech Provider App Review** (whatsapp_business_messaging + whatsapp_business_management advanced access) ছাড়া অন্য কোম্পানির নম্বর যুক্ত করা যাবে না — রিভিউর ভিডিও দুটো করে জমা দেওয়া এখনই দরকার (`docs/meta-app-review.md`)।
- ISP Digital-এর কোনো অফিসিয়াল API নেই; প্যানেল বদলালে সব কোম্পানির বট একসাথে ভাঙতে পারে — তাই প্রতি ঘণ্টায় একটা স্বয়ংক্রিয় স্বাস্থ্য-পরীক্ষা আর অ্যালার্ট রাখব। SoftifyBD-র সাথে আনুষ্ঠানিক অনুমতি/API নিয়ে কথা বলা ভালো।
- প্রতিটা কোম্পানির Groq-এর ফ্রি লিমিট আলাদা; বড় ISP-র জন্য পেইড key লাগতে পারে — সেটআপ পেজে সতর্কবার্তা থাকবে।
- কাস্টমারের ডেটা (নাম, ফোন, বিল) — গোপনীয়তা নীতি ও শর্তাবলী লাগবে।
