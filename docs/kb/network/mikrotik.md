## সেলস অংশ
- **কোন সমস্যা:** কোন কাস্টমার অফলাইন, কার লাইন ব্লক — রাউটারে ঢুকে খুঁজতে হয়।
- **কী পাবেন:** MikroTik রাউটার থেকে সরাসরি অনলাইন অবস্থা ও সেশন পড়া, আর রাউটারের তথ্য সরাসরি স্ক্রিনে।
- **কাদের জন্য:** যাঁদের একাধিক MikroTik রাউটার আছে।
- **আপত্তি:** "রাউটারে কিছু বদলে যাবে?" — Desk শুধু পড়ে; লাইন বন্ধ/চালুর সময় ছাড়া রাউটারে লেখে না।
- **যা নেই:** রাউটারের ফায়ারওয়াল বা কনফিগারেশন Desk থেকে বদলানো যায় না।


## কী ও কেন
Desk প্রতিটা কোম্পানির MikroTik রাউটারের সাথে যুক্ত হয়। কাস্টমার কি অনলাইন, কোন প্রোফাইলে আছে, লাইন ব্লক কি না, এসব তথ্য রাউটার থেকে সরাসরি পড়া হয়। লাইন বন্ধ/চালুর কাজও এই রাউটারে গিয়ে হয় (line.enable_disable)।

## কীভাবে কাজ করে
- **পড়া:** Desk রাউটারের API (ক্লাসিক বাইনারি, পোর্ট ৮৭২৮ বা TLS ৮৭২৯) ব্যবহার করে। Desk রাউটারে কোনো সেটিং বদলায় না, শুধু পড়ে।
- **PPPoE তথ্য (প্রতি ২ মিনিটে):** গ্রাহকের secret ও profile পড়ে। profile বা তার pool-এর নামে `block`, `disabl`, `suspend` বা `unpaid` থাকলে গ্রাহককে ব্লক ধরা হয়। সক্রিয় সেশন গণনায় ব্লক বাদ যায়।
- **ব্লক profile:** `mikrotik_routers.block_profile`-এ নির্দিষ্ট করা যায়। না থাকলে `BLOCKED-PROFILE` নামের profile খোঁজা হয়।
- **লেখা:** একমাত্র লেখার কাজ লাইন বন্ধ/চালু (Desk পথ, সুইচ `line_control`) আর রাতের ব্যাকআপে ফাইল বানানো ও মোছা। রাউটারের ইউজারের write অনুমতি লাগে।
- **ব্যাকআপ:** রাতে রাউটারের ব্যাকআপ নেওয়া হয়। ব্যাকআপ কতদিন রাখা হবে তা "নেটওয়ার্ক সেটিংস"-এ। এর চেয়ে পুরনোগুলো রাতে নিজে মোছে।
- **রিমোট পোর্ট:** টিকিট ও ইনবক্সে কাস্টমারের IP-তে ক্লিক করলে রাউটারের ওয়েব পেজ খোলে। রিমোট পোর্ট দেওয়া থাকলে সেই পোর্টে।
- **ফাইল পড়া:** RouterOS নতুন না হলে ফাইল পড়তে SSH বা FTP ব্যবহার হয়।

## কীভাবে করবেন
1. মেনু **MikroTik** (পাতার নাম "নেটওয়ার্ক সেটিংস")
2. রাউটারের তালিকা দেখুন। প্রতিটা রাউটারের অবস্থা ও শেষ পড়ার সময় থাকে।
3. রাউটার যোগ বা বদলালে ঠিকানা ও API ইউজার দিন। পাসওয়ার্ড এনক্রিপ্টেড থাকে।
4. ব্যাকআপ সীমা ও রিমোট পোর্ট ঠিক করে সেভ করুন।
5. রাউটারে কাস্টমার কোন profile-এ আছে দেখতে কাস্টমার পেজের "লাইভ অবস্থা" দেখুন।

## সাধারণ প্রশ্ন
- **রাউটার অফলাইন দেখাচ্ছে কেন?** ঠিকানা, পোর্ট বা API ইউজারের অনুমতি সমস্যা, বা রাউটার সত্যিই বন্ধ। রাউটারের ফায়ারওয়াল Desk-এর ঠিকানা আসতে দিচ্ছে কি না দেখুন।
- **কাস্টমার ব্লক হয়ে আছেন কেন?** তাঁর secret-এর profile ব্লক। বিলের কারণে বন্ধ থাকতে পারে।
- **Desk কি রাউটারে সেটিং বদলায়?** শুধু লাইন বন্ধ/চালুর কাজে, আর রাতের ব্যাকআপ ফাইলে। অন্য কোনো সেটিং নয়।
- **ব্যাকআপ কোথায় থাকে?** রাউটারের ফাইল হিসেবে নেওয়া হয়ে Desk-এ সংরক্ষিত হয়। রাতে পুরনোটা মোছে।
- **রিমোট পোর্ট না দিলে কী হয়?** IP-তে ক্লিক করলে শুধু `http://IP` খোলে।

| লগইন ব্যর্থ | API ইউজারের পাসওয়ার্ড ও অনুমতি | ভুল পাসওয়ার্ড বা read/write অনুমতি নেই | ইউজার ঠিক করুন |

| কাস্টমার অনলাইন, অথচ ইন্টারনেট নেই | secret-এর profile | ব্লক profile সক্রিয় | লাইন চালু করুন (line.enable_disable) |
| কাস্টমার রাউটারে নেই | PPPoE secret | secret মোছা বা অন্য রাউটারে | রাউটার ও ONU তালিকা মেলান (network.olt) |

## সীমা ও যা নেই
- Desk রাউটারের কনফিগারেশন (ফায়ারওয়াল, IP, ইউজার) বদলায় না; সেগুলো রাউটারে নিজে করতে হয়।
- কাস্টমারের পাসওয়ার্ড বা IP কোথাও প্রকাশ করা হয় না; কাস্টমারকে বটও এগুলো বলে না।
- কিছু পুরনো RouterOS সংস্করণে ব্যাকআপ ফাইল পড়া সীমিত।
